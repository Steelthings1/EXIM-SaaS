# Module 16 REST API Specification

## Endpoints Summary

### 1. 10-Dashboard Intelligence Suite API
- `GET /api/analytics/suite?view=EXECUTIVE`: Retrieve telemetry and YoY trends for any of the 10 specialized dashboard views (`EXECUTIVE`, `DESTINATION_MARKETS`, `EXPORT_SALES`, `VESSEL_CONTAINER`, `BUYER_PERFORMANCE`, `VENDOR_PROCUREMENT`, `MULTI_WAREHOUSE`, `FINANCIAL_TREASURY`, `SANCTIONS_RISK`, `AI_PREDICTIVE`).
