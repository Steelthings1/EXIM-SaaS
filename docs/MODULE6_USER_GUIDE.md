# Module 6 End-User Setup & Usage Guide

## Step-by-Step Cascading Document Engine Guide

### Step 1: Cascading Document Field Editor
1. Navigate to `/documents/cascading-editor`.
2. Edit master order attributes (quantity, unit price, freight) and view live cascading updates across downstream documents.

### Step 2: Document Version Control Audit Trail
1. Navigate to `/documents/version-history`.
2. Audit document revision history, author signatures, and cryptographic SHA-256 checksums.
