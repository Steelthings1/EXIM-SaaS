# Module 20 End-User Setup & Usage Guide

## Step-by-Step Multi-Currency Finance & Forex Treasury Guide

### Step 1: Multi-Currency Commercial Invoices
1. Navigate to `/finance/multi-currency-invoices`.
2. Input buyer name, currency (USD, EUR, GBP, AED), foreign amount, FX rate, and GST LUT reference to issue zero-rated export invoices.

### Step 2: Forex Realized Gain/Loss Calculator
1. Navigate to `/finance/forex-treasury`.
2. Input booked exchange rate vs realized bank conversion rate to determine net FX gain or loss in INR.
