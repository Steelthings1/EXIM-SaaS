# Module 25 End-User Setup & Usage Guide

## Step-by-Step Settings & Audit Logs Guide

### Step 1: Workspace System Settings
1. Navigate to `/settings/workspace`.
2. Configure base currency, system timezone, custom domain alias, and official export document header/footer text.

### Step 2: Security Audit Trail & Activity Logs
1. Navigate to `/settings/audit-logs`.
2. Monitor timestamped security activity logs, modified entity fields, user actions, and IP tracking records.
