# Module 29 End-User Setup & Usage Guide

## Step-by-Step Developer Portal V3 Guide

### Step 1: Developer API Keys V3
1. Navigate to `/developer/api-keys-v3`.
2. Generate live API keys (`exim_live_...`) and configure rate limit quotas for external system integrations.

### Step 2: Webhook Subscriptions V3
1. Navigate to `/developer/webhook-subscriptions-v3`.
2. Register target listener HTTP endpoints for real-time trade events (`shipment.updated`, `customs.cleared`, `ebrc.issued`) and verify HMAC SHA-256 signatures.
