# Module 11 REST API Specification

## Endpoints Summary

### 1. Multi-Carrier Freight Aggregator API
- `GET /api/logistics/freight-aggregator`: Retrieve spot ocean/air freight quotes across carriers.
- `POST /api/logistics/freight-aggregator`: Calculate itemized freight quote surcharges.

### 2. Shipping Instructions API
- `GET /api/logistics/shipping-instructions`: Fetch submitted SI dispatch records.
- `POST /api/logistics/shipping-instructions`: Submit Shipping Instructions (SI) for draft Bill of Lading creation.
