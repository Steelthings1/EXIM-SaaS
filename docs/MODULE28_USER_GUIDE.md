# Module 28 End-User Setup & Usage Guide

## Step-by-Step Security Telemetry & Anomaly Guide

### Step 1: Security Activity Logs & Audit Trail
1. Navigate to `/security/activity-logs`.
2. Inspect timestamped user sessions, IP addresses, entity modification diffs, and risk ratings. Export audit trail to CSV.

### Step 2: Security Anomaly Alerts
1. Navigate to `/security/alerts`.
2. Review real-time threat alerts for unrecognized IP logins and high-value order edits, and resolve alerts once investigated.
