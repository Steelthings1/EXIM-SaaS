# Module 30 End-User Setup & Usage Guide

## Step-by-Step Ecosystem Directory & RFQ Guide

### Step 1: Ecosystem Partner Directory
1. Navigate to `/marketplace/ecosystem-directory`.
2. Filter vetted partners by seaport/ICD code (e.g. INMAA1, INPAV1, AEDXB) and service category (Customs Broker, Freight Forwarder, NABL Lab).

### Step 2: Service RFQs Collaboration Ledger
1. Navigate to `/marketplace/service-rfqs`.
2. Monitor dispatched RFQ status transitions (`Submitted` → `Quote Received` → `Booked` → `Fulfilled`).
