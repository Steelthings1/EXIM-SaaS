# Module 10 REST API Specification

## Endpoints Summary

### 1. International Sales Contracts API
- `GET /api/sales/contracts-v2`: Retrieve sales contracts registry and UN CISG governing terms.
- `POST /api/sales/contracts-v2`: Create a new sales contract and trigger AI legal risk audit.

### 2. AI Contract Legal Auditor API
- `POST /api/sales/contract-audit`: Perform deep legal risk scan on contract clause parameters.
