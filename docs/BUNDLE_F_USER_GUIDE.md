# Bundle F End-User Setup & Usage Guide

## Step-by-Step Platform Realization Guide

### Step 1: Multi-Modal AI Copilot
1. Navigate to `/ai/copilot`.
2. Toggle tabs to ask Document RAG compliance questions, issue Voice Assistant commands, or run Packaging Label Vision Scans.

### Step 2: 10-Dashboard Operational Intelligence Suite
1. Navigate to `/analytics/multi-dashboards`.
2. Click any of the 10 view tabs (Executive, Country, Sales, Shipment, Customer, Supplier, Inventory, Financial, Risk, AI Insights) to monitor live platform KPIs.

### Step 3: Country Knowledge Base
1. Navigate to `/kb/country-intelligence`.
2. Inspect destination market customs authorities, food packaging rules, and FTA preferences.

### Step 4: Developer API & Webhooks Portal
1. Navigate to `/developer/api-center`.
2. Manage production API keys, rate limits, and webhook listeners with HMAC SHA-256 signatures.

### Step 5: Ecosystem Marketplace Directory
1. Navigate to `/marketplace/directory`.
2. Book verified Customs House Agents (CHAs), Freight Forwarders, and NABL testing labs.
