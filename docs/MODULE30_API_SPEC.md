# Module 30 REST API Specification

## Endpoints Summary

### 1. Ecosystem Partners V3 API
- `GET /api/marketplace/partners-v3`: Query vetted ecosystem partner profiles with optional port code and service category filters.
- `POST /api/marketplace/partners-v3`: Register a new partner company profile.

### 2. Service RFQs API
- `GET /api/marketplace/service-rfqs`: Fetch dispatched service Request for Quotations (RFQs).
- `POST /api/marketplace/service-rfqs`: Submit a new service RFQ to a partner.
