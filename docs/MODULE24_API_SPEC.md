# Module 24 REST API Specification

## Endpoints Summary

### 1. In-App Notifications API
- `GET /api/notifications/in-app`: Fetch real-time alert feed & unread badge count.

### 2. Notification Preferences API
- `GET /api/notifications/preferences`: Fetch delivery channel preferences.
- `POST /api/notifications/preferences`: Update delivery channel preferences (In-App, Email, SMS).
