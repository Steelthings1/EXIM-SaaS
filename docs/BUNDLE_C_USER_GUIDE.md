# Bundle C End-User Setup & Usage Guide

## Step-by-Step Manufacturing & QC Guide

### Step 1: Manufacturing Production Batches
1. Navigate to `/production/batches`.
2. Schedule factory manufacturing batch runs and track yield efficiency percentages.

### Step 2: Quality Control & Lab Testing
1. Navigate to `/qc/inspections`.
2. Log NABL / ISO 17025 laboratory test results (moisture content %, active ingredient purity %, heavy metal PPM).

### Step 3: 3D Container Loading Planner
1. Navigate to `/qc/container-loading`.
2. Select container type (20ft STD / 40ft HC), input total gross weight (kg) and volume CBM (m³).
3. Review payload weight & volume utilization meters and register high-security bolt seal numbers.

### Step 4: Export Statutory Certificates Vault
1. Navigate to `/certificates/vault`.
2. Click **Auto-Draft Official Document with AI Agent** to generate Phytosanitary, CoA, and Health Certificates for customs clearance.
