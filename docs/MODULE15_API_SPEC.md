# Module 15 REST API Specification

## Endpoints Summary

### 1. Copilot Chat API
- `POST /api/ai/copilot-chat`: Process Document RAG queries and voice assistant commands.

### 2. Label Vision API
- `GET /api/ai/label-vision`: Fetch past packaging label inspection logs.
- `POST /api/ai/label-vision`: Execute computer vision packaging label regulatory audit.
