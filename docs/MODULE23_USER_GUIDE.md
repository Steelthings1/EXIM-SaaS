# Module 23 End-User Setup & Usage Guide

## Step-by-Step Workflow Automation & Approvals Guide

### Step 1: Executive Approval Requests & Sign-Off
1. Navigate to `/workflow/approvals`.
2. Input order reference, amount ($ USD), and approval type. Orders exceeding $50,000 automatically trigger Chief Trade Officer sign-off requests.

### Step 2: Automated Reminder Rules & Alerts
1. Navigate to `/workflow/reminders`.
2. Configure automated alerts for expiring LCs (7-day threshold), open EDPMS records (30-day threshold), or port customs queries.
