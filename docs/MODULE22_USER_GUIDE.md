# Module 22 End-User Setup & Usage Guide

## Step-by-Step Export Incentive Realization Guide

### Step 1: Export Incentive Claims V3
1. Navigate to `/incentives/claims-v3`.
2. Input Shipping Bill number, incentive scheme (RoDTEP, RoSCTL, Duty Drawback), FOB realization INR, and HS code to issue e-scrip scroll.

### Step 2: DGFT e-Scrip Credit Balance Ledger
1. Navigate to `/incentives/escrip-ledger`.
2. Select e-scrip scroll and input import Bill of Entry (BOE) details to offset basic customs duty.
