# Module 12 End-User Setup & Usage Guide

## Step-by-Step Satellite AIS & Container Telemetry Guide

### Step 1: Satellite AIS Live Telemetry Map
1. Navigate to `/logistics/ais-telemetry`.
2. Input MMSI numbers, latitude/longitude coordinates, speed in knots, compass heading, and destination ETA predictions to track live vessel positions.

### Step 2: Container Milestone Pipeline
1. Navigate to `/logistics/container-milestones`.
2. Log container events across the 7-stage pipeline (Gate-In, Vessel Loaded, Departed Port, Transshipment, Port Arrival, Customs Hold, Out of Charge).
