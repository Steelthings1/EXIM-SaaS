# Module 9 REST API Specification

## Endpoints Summary

### 1. Export Quotations API
- `GET /api/sales/export-quotations`: Retrieve export sales quotations registry.
- `POST /api/sales/export-quotations`: Create a new export quotation with margin analysis.

### 2. Margin Analysis API
- `GET /api/sales/margin-analysis`: Fetch aggregate margin analytics and top-performing quotations.
