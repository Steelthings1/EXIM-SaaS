# Module 7 REST API Specification

## Endpoints Summary

### 1. Manufacturing Orders API
- `GET /api/production/manufacturing-orders`: Retrieve manufacturing order scheduling and yield statuses.
- `POST /api/production/manufacturing-orders`: Process batch yield output and evaluate 90% threshold.

### 2. Yield Analytics API
- `GET /api/production/yield-analytics`: Fetch line performance metrics and average yield efficiency percentages.
