# Module 18 End-User Setup & Usage Guide

## Step-by-Step Statutory License Vault Guide

### Step 1: Access Statutory Vault Workspace
1. Navigate to `/settings/statutory-vault`.

### Step 2: Register New License
1. Select category (IEC, RCMC, AD Code, APEDA, FSSAI, ICEGATE Port).
2. Input license number, issuing authority, and expiry date.
3. Click "Validate & Deposit License into Vault" to track expiry telemetry and receive auto-renewal warnings.
