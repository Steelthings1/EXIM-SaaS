# Module 11 End-User Setup & Usage Guide

## Step-by-Step Freight Aggregator & Shipping Instructions Guide

### Step 1: Multi-Carrier Freight Rate Aggregator
1. Navigate to `/logistics/freight-aggregator`.
2. Input POL, POD, and container equipment types to compare spot ocean freight rates across MSC, CMA CGM, and Maersk with THC/BAF surcharge breakdowns.

### Step 2: Shipping Instructions (SI) Dispatch
1. Navigate to `/logistics/shipping-instructions`.
2. Submit Shipping Instructions (SI) payloads with vessel, voyage, container, and seal numbers for Bill of Lading generation.
